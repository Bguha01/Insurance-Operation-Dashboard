# Insurance Operations Performance Dashboard

## Overview
A portfolio practice project analyzing fictional insurance operations records to track case outcomes, turnaround time (TAT), SLA compliance, and rework.

## Dataset
`insurance_operations_sample_data.csv` contains 300 synthetic records. No real customer, employer, or policy data is included.

## Tools
- Microsoft Excel: KPI summary, filters, charts
- Python/pandas (optional): basic exploratory analysis

## Key questions
1. How many cases are completed or pending?
2. What is the SLA breach rate?
3. Which case types occur most frequently?
4. What is the average processing TAT?
5. How many cases require rework?

## Files
- `Insurance_Operations_Performance_Dashboard.xlsx` — dashboard, case data, and notes
- `insurance_operations_sample_data.csv` — source dataset
- `analysis.py` — optional Python exploration

## How to use
Open the Excel workbook and start on **KPI Dashboard**. Inspect or filter records on **Case Data**. Use the CSV to extend the project in SQL, Python, or Power BI.

## Important
This is a self-directed learning project using synthetic data. Do not present it as work completed for an employer or client.
